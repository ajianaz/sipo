## Risk Register

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| Flutter SDK version conflict | Low | High | Pin Flutter version in CI, FVM |
| Drift code-gen issues | Medium | Low | Run `build_runner` after each schema change, commit generated files |
| Decimal precision bugs | Medium | Medium | Comprehensive decimal validator unit tests |
| CI flakiness | Low | Medium | Minimal CI (lint + test only), no emulator-dependent tests |
| Scope creep | High | Medium | Strict milestone gating — no new features until M4 complete |
